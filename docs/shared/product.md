# 产品约束

BuildURProfile 将文本型 PDF 简历转成桌面优先的交互式作品网页（Showcase）。用户必须核对内容、完成测评并审阅结果，才主动选择正式分享或作品集交付。

## 产品本体与交付产物区分

- **产品本体（BuildURProfile 生成器）**：是由 Next.js 全栈服务与 Python LangGraph Agent 组成的在线 Web 应用。**产品本体不部署到 GitHub Pages，也不作为离线静态包分发。**
- **最终产物（用户作品集 Showcase 页面）**：是用户经过 PDF 解析、字段确认与风格测评后生成的个人作品集展示页，由 `DesignConfig` 驱动渲染，支持通过公开分享链接或作品集导出包交付。

## 展示与测评

- 用户角色为 UI/UX 设计师、前端/创意开发、品牌/动效/文案三类。
- 固定 Marquee + StackedCards 骨架；三种皮肤为 `dark-tech`、`light-minimal`、`high-saturation`。个性化只调整允许的参数与 Design Tokens。
- 八题产生 E/K/P/S 四个归一化分数，并保留离散的 `PChoice`。E 控制表现程度，K 控制动效，P 表示视觉基调，S 表示浏览与操控倾向；P 不是可随意插值的色相。
- 网页、编辑器与导出产物使用受校验的 `DesignConfig`。文案以文本节点渲染，不接收可执行页面代码。
- 支持键盘操作、焦点可见性和 `prefers-reduced-motion`；触屏应提供可点击的操作方式。
- 项目正文、完整技能和不能可靠分段的经历原文仍应可读，不为视觉排版捏造或丢弃履历。

## 内容与交付

PDF、提取全文、解析中间结果和来源片段留在浏览器内存。用户确认后的展示字段才可进入生成任务；扫描件 OCR 未接入。

免费生成、编辑与预览不授予正式交付资格。用户主动付费后，同项目可正式分享和导出作品集网页包；分享默认 7 天有效，可撤销；已下载的导出包无法撤回。发布与下载必须由服务端核对所有权和支付资格。

## 肖像与范围

肖像为可选的本机演示，生成静态插画画面并保留风格背景。照片只在主动提交后上传，需向用户说明第三方图像处理。当前 Wibi 资源仅限非商业预览，禁止进入付费交付。

当前不提供扫描件 OCR、账号协作/CMS、任意模板或页面代码生成、3D 模型、多朝向图集及指针转向。未来功能需另行确定产品范围与验收合同。

实现边界见[架构与协议](architecture.md)，交付要求见[支付文档](../api/payment.md)。
