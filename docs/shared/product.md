# 产品约束

BuildURProfile 将 PDF 简历转成桌面优先的交互式作品网页（Showcase）。用户核对内容、选择固定模板并审阅结果后，才主动选择正式分享或作品集交付。

## 产品本体与交付产物区分

- **产品本体（BuildURProfile 生成器）**：是由 Next.js 全栈服务与 Python LangGraph Agent 组成的在线 Web 应用。**产品本体不部署到 GitHub Pages，也不作为离线静态包分发。**
- **最终产物（用户作品集 Showcase 页面）**：是用户经过 PDF 解析、字段确认与模板选择后生成的个人作品集展示页，由 `DesignConfig` 驱动渲染，支持通过公开分享链接或作品集导出包交付。

## 展示与模板

- 用户角色为 UI/UX 设计师、前端/创意开发、品牌/动效/文案三类。
- 新流程提供四个固定模板：赛博科技、温暖创意、理性简约、大胆实验。赛博科技使用独立页面骨架与自有默认立体人物；其他模板及旧作品沿用 Marquee + StackedCards 骨架。生成任务不调用 MotionSites MCP，不内嵌其人物或项目素材。
- 新流程不再要求八题偏好选择。旧浏览器解析兼容入口与运行中的旧任务继续使用版本化答案合同；E/K/P/S 仅用于这些旧合同及兼容参数。
- 网页、编辑器与导出产物使用受校验的 `DesignConfig`。文案以文本节点渲染，不接收可执行页面代码。
- 支持键盘操作、焦点可见性和 `prefers-reduced-motion`；触屏应提供可点击的操作方式。
- 项目正文、完整技能和不能可靠分段的经历原文仍应可读，不为视觉排版捏造或丢弃履历。

## 内容与交付

P0 原 PDF、来源块与私有草稿在受会话保护的服务端从上传起保留 30 天，到期自动清理，用户可提前删除；上传前披露期限和供应商。配置的文本供应商仅接收按规则锚点逐条格式化所需的文字。旧浏览器候选及来源仍只留在浏览器内存。用户确认后的展示字段才可进入生成任务；无文字扫描页可由用户主动选择本机 OCR。

新 Agent 简历确认后的展示合同为 `resume-v3`，按 A–D 分类；旧 `resume-v1/v2` 保留兼容：A 为基本信息、求职意向、自我评价；B 为教育、工作、项目、荣誉奖项、校园经历；C 为专业技能；D 为其他内容。每类允许为空。浏览器规则解析只提出有 PDF 依据的候选内容，用户可决定展示、修改或重新分类；电话、年龄等个人信息和期待薪资默认不展示。确认后的合同不含 PDF 来源摘录，作品页只渲染有内容的模块。

低置信度条目需主动核对；隐藏模块也须明确确认，编辑不自动完成核对。新版“解析与补充”页以模块开关决定普通内容条目展示：显示模块时，其下全部条目默认进入作品；隐藏模块时，其下条目均不进入作品。基本信息是网站身份与联系设置，不使用模块总开关：已勾选姓名进入首屏，已勾选邮箱或电话进入底部联系区；年龄等其他字段与该模块补充内容只留在私有草稿，不进入新作品。条目级“展示此条”勾选框已移除，旧草稿中的 `item.included` 仅作兼容字段，不决定展示。姓名和邮箱/电话的字段级“用于网站”选择仍保留，未选字段不进入作品。补充文字、命名链接和图片与原条目绑定，全份图片最多 24 张 / 50 MiB。来源信息也不进入作品。

无肖像生成成功自动建立免费作品草稿，作品图片独立于 30 天原件保留，删除原简历不丢失已有作品图片。生成、编辑、预览和单文件作品集导出免费；正式发布分享须由用户主动付费。分享默认 7 天有效，可撤销；已下载的导出文件无法撤回。发布由服务端核对所有权和支付资格，下载由服务端核对所有权。

## 肖像与范围

肖像为可选内容，照片只在主动提交后上传，需向用户说明第三方图像处理。导出将生成的肖像嵌入离线页面。

当前不提供账号协作/CMS、任意模板或页面代码生成、可操纵的 3D 模型、多朝向图集及指针转向。未来功能需另行确定产品范围与验收合同。

实现边界见[架构与协议](architecture.md)，交付要求见[支付文档](../api/payment.md)。
