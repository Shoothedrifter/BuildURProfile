# 支付与交付

正式分享和作品集导出使用支付宝「AI 网页应用收款」的 `alipay.trade.page.pay`。同一服务端项目一次付款解锁两种交付，新项目独立计费。免费生成、编辑和预览不需要付款。

## 配置

实际加载方式与样例复制目标见[部署与环境变量](../shared/deployment.md)。生产配置从进程环境注入，或由 Next.js 启动器读取根 `.env`；Compose 使用根 `.env.api` 注入。生产不读取沙箱 JSON。

| 变量 | 要求 |
| --- | --- |
| `PAYMENT_ENV` | `sandbox` 或 `production` |
| `PAYMENT_PRICE_FEN` | 自行确定的正整数分；本机沙箱价格不得当作生产售价 |
| `PUBLIC_BASE_URL` | 站点 origin，无路径、查询或片段；生产必须为 HTTPS |
| `ALIPAY_APP_ID` | 当前环境的应用 ID |
| `ALIPAY_PRIVATE_KEY`、`ALIPAY_PRIVATE_KEY_TYPE` | 用户自持应用私钥及匹配的 `PKCS1` / `PKCS8` 格式 |
| `ALIPAY_PUBLIC_KEY` | 对应环境的支付宝公钥 |
| `ALIPAY_SELLER_ID` / `ALIPAY_SELLER_EMAIL` | 商户身份，至少提供一项 |
| `ALIPAY_NOTIFY_URL` | 生产必填：无重定向的公网 HTTPS `/api/payment/notify`，无查询或片段 |

网关按支付环境由代码选择，不接收客户端自报网关。浏览器只提交官方 SDK 生成且网关经校验的 POST 支付表单。未完整配置支付时，结账不可用，但预览仍可使用。

沙箱可读取仓库根 `.alipay-sandbox.json` 中同一应用的凭据和商户身份。该文件由支付宝接入工具准备，在类 Unix 环境必须为普通文件且权限 `0600`；代码会在内存中使用文件值，不要再复制私钥到样例或前端。容器不打包此文件，按环境变量配置沙箱凭据。

## 核实与恢复

1. 用户主动请求分享或导出后，服务端保存项目并展示服务内容、服务端售价与交付说明。
2. 用户自行在收银台付款；返回 `/payment/return` 后服务端签名调用 `alipay.trade.query`，核对订单号、金额、应用及商户身份和交易状态。
3. 只有有效的 `TRADE_SUCCESS` / `TRADE_FINISHED` 查单或签名通知才能发放资格，再继续原交付动作。同项目的另一种交付不重复收费。

通知验签、字段核对、幂等处理和资格发放都在服务端；收银台页面、二维码状态和客户端消息不能证明付款成功。缺通知时通过签名查单补偿，付款后交付失败保留资格。

当前会复用同项目的待支付订单。二维码报错不能直接作为关闭订单的依据；先签名查单，不直接改数据库为已付款或作废，避免漏记迟到付款和重复收费。

## 沙箱操作

- 使用沙箱买家，买家账号与支付密码从已校验的沙箱配置或官方控制台取得，不使用真实支付宝账户或猜测值。
- 电脑收银台优先使用“登录支付宝账户付款”；页面要求的支付密码由用户自行输入，开发者不代为输入密码或点击最终付款。
- 如需扫码，使用官方 Android 沙箱支付宝。普通支付宝和 iOS 客户端不作为沙箱扫码验收方式，安装说明见[官方沙箱工具](https://open.alipay.com/develop/sandbox/tool)。
- 失败时记录可见错误并重新签名查单，核对网关和商户身份。查单为 `ACQ.TRADE_NOT_EXIST` 不代表付款成功。
- localhost 无法接收支付宝服务器通知；可验证返回后查单，公网回调需另行部署验收。

## 上线验收

以下事项均需独立完成，历史办理记录和自动测试不证明已完成验收：

- 复核当前产品签约与应用上线状态，完成商家平台收款信息；不要沿用旧文档中的“已提交”作为生效证明。
- 使用生产独立密钥与数据库，提供公网 HTTPS 站点与通知接口，核实通知可 POST 且不重定向。
- 验证通知验签、应用/订单/金额/商户/交易状态检查、重复通知的 `success` 回写和漏通知查单补偿。
- 由用户完成真实小额付款；确认原分享或导出动作恢复，同项目另一交付不再收费，另一项目仍需付费。
- 检查分享 `#share=…`、7 天过期/撤销、导出包断网打开、刷新与重启后资格持久化；未付费交付请求必须被拒绝。
- 验证退款和售后核对流程；订单记录可供人工核对，当前不提供自动退款后台。仅在核实全额退款后撤销资格与有效分享。

Wibi 肖像目前禁止进入付费分享和导出，相关门槛见[Agent 说明](../agent/README.md)。
