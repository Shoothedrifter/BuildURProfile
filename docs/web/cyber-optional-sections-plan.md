# 赛博科技校园经历与荣誉奖项实施计划

**目标**　校园经历与荣誉奖项各自适应从零到多条的内容。没有图片、数字或结构化字段的作品集仍应完整、易读。有明确信息时，再突出成果和证据。

**范围**　P0 在 `dev/noodle` 更新赛博科技的两处分区。继续使用「解析与补充」已确认的 `resume-v3` 数据。预览、分享和单文件 HTML 均使用同一个渲染器。P1 再调整编辑页的展示提示、能力区及整页间距。

**实现**　React、TypeScript、现有 CSS 和 HTML 导出构建。沿用 [赛博科技模板规格](cyber-creator-p0-spec.md) 的确认内容边界、条目顺序和既有交付规则。

## 展示规则

| 已确认的输入 | 渲染行为 |
| --- | --- |
| 模块缺失、已关闭或无有效条目 | 省略整个分区，包括标题、占位、动效和该分区的任何入口。 |
| 单条纯文字 | 显示紧凑条目。标题、正文、补充说明按原意展示，长文本换行。有独立详情原文时才显示「查看详情」。 |
| 多条内容 | 按用户确认的条目顺序逐条展示。单个汇总条目仍作为一条内容。 |
| 已确认的日期、组织、角色、级别 | 信息边界明确时作为元信息展示；否则保留在已确认文字中。 |
| 明确的数字与含义 | 可从已公开标题、正文或已勾选字段中提取短成果。只突出能对应到具体含义和单位的原文片段。 |
| 仅有补充文字、图片、链接或详情原文 | 条目仍然可见。图片和链接跟随原条目。有详情原文时提供展开入口。 |

荣誉计数仅展示原文明确声明的总数和分类。年份、GPA、名次及百分比保留各自的含义。比如「竞赛奖项 60 项」可以突出展示，只有已确认文字写明各级别的获奖数才显示分布。校园条目中的「互动量增长 40%」可以完整突出，「40%」单独出现时保留原排版。提取结果仅用于排版，全文及证据仍可访问。

## P0 实施步骤

1. **确定展示边界与回归样例。** 在 `apps/web/src/lib/cyber-creator-presentation.test.ts` 和 `apps/web/src/components/CyberCreatorPage.test.tsx` 增加合成样例，覆盖模块缺失、空条目、单条纯文字、多条、仅有补充素材和长文本。沿用 `projectConfirmedResumeV3` 处理模块开关和字段选择，沿用 `resumeItemHasContent` 判断有效内容。渲染层读取已排序的 `sections`，保留 `#campusExperience`、`#awards` 锚点和原条目 ID。
2. **改造校园经历。** 新增 `CyberCampusSection`，接收已确认的条目和现有图片解析器。版式先呈现角色与贡献，再按数据展示日期、成果和补充资料。单条采用紧凑的实践条目，多条采用纵向列表。保留原生 `details` 展开，避免固定高度裁切全文。由 `CyberCreatorPage.tsx` 分派，版式写入 `styles.css`。
3. **改造荣誉奖项。** 新增 `CyberAwardsSection`，使用相同的入参边界。单条纯文字用紧凑展示，多条用奖项列表。只有确认内容满足上表条件时才加成果数字，其他数字和说明按原样可读。继续复用现有补充素材渲染和图片解析器。测试验证奖项顺序、汇总数字不合成、缺素材不产生证书入口。
4. **加入轻动效。** 内容默认直接可见。校园成果进入视口时提亮一次，荣誉项短暂错峰显现。动效只调整表现，保持文字位置稳定且按钮可立即操作。减少动态效果模式和缺少视口观察能力的环境使用完整静态版；导出资源随现有构建内嵌。
5. **验证交付。** 在 `apps/web/src/lib/export.test.ts` 验证分区、省略规则、详情和素材归属。运行 `npm test`、`npm run build` 和 `git diff --check`。桌面与窄屏实测页面滚动、键盘展开、减弱动效，以及阻断外网时的单文件导出。

## 发布前验收

- 两块都缺失、只展示其中一块，以及用户隐藏已有内容。没有空标题、空白段或失效锚点。
- 单条纯文字、多条奖项、仅有补充素材、长标题及展开全文。来源顺序正确，内容完整可访问。
- 明确数字可以突出。年份、模糊数字和未确认字段不会变成成果，图片和链接不会串到其他条目。
- 用合成数据验证上述结构，再在本机以现有作品集核对两项校园成果和竞赛统计。预览、分享模板和新导出的 HTML 呈现一致。

## P1

- 在「解析与补充」的校园、荣誉条目里按需显示一条「在作品集中的展示方式」提示，区分首层内容、详情与附件。模板在后续步骤选择，因此通用编辑页使用字段用途说明。
- 收紧能力区和全站章节间距。跨模块重复内容供用户核对，公开范围和顺序继续由用户决定。
