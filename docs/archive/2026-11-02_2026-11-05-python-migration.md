## 重要决定与结果

- 2026-11-02 至 11-03：明确完整生成应经过图与受限 Skill 注册表。选择 Python 作为内部 LangGraph 服务，Node 保持唯一公开 API、支付与交付边界；生图改用外部 API，不在服务器部署模型。
- 2026-11-05：迁移记录表明 `apps/agent` 已成为唯一生成消费者，旧 JS worker、JS LangGraph 运行依赖和本地模型安装脚本移除。API 模式无照片作品也经过 Python 图，Pages 保留浏览器 TS 路径。
- Node 独占数据库与资产，Python 经服务令牌和租约读写本任务；checkpoint 单独持久化。新增版本化合同、跨语言黄金样例、Node↔Python 集成及容器入口。
- 肖像默认供应商切为 Cloudflare Workers AI FLUX.2 Klein 4B，保留 OpenAI 可选适配器。Wibi 资源固定提交并校验，生产和付费交付继续禁用未经商业授权的肖像。
- 当时记录无照片、模拟肖像、跨语言规则及现有 Web/支付/Pages/导出回归已覆盖；不在此复制逐次测试数量或分支状态。
